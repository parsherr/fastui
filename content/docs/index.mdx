Welcome to **FastUI** – a modern component library for React and Next.js projects.

## What is FastUI?

FastUI provides a set of beautifully crafted, accessible UI components and templates built on top of [shadcn/ui](https://ui.shadcn.com). Copy and paste components directly into your project and customize them to fit your design system.

## How to use

Browse the available components in the sidebar. Each component page includes a live preview, code snippet, and installation instructions.

## Next steps

- Check out the [installation guide](/docs/installation) to get started.
- Browse [components](/docs/components/alert-dialog) to see what's available.
- Add your own components and templates to the library.

## Key Features

- **Reusability**: components are designed to be composable and reusable across your project.
- **Type safety**: fully typed with TypeScript — catch errors at compile time.
- **Accessible**: built on Radix UI primitives for keyboard and screen reader support.
- **Beautiful**: focus on aesthetics with smooth animations via Framer Motion.
