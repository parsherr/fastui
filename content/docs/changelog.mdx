## July 2025 - Alert Dialog Component

Added the first fully documented component: **Alert Dialog** — a dialog that requires user response before proceeding. Includes live preview, code snippet, and installation guide.

## July 2025 - Project Launch

FastUI launched as an open-source component library built on shadcn/ui and Next.js 15. The project provides beautifully crafted, accessible UI components with copy-paste installation.

### Initial Components

- 24 shadcn/ui base components available in `components/ui/`
- Live preview system for component documentation
- MDX-driven docs with syntax highlighting and copy buttons

## June 2025 - CLI Tool

We've released a CLI tool to simplify adding components to your project.

You can check it out in the [CLI](/docs/cli) section.
